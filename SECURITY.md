# Security Policy

## Reporting

Do not disclose suspected vulnerabilities in a public issue. Send a private report to the repository owner with the affected version, reproduction steps, impact and the smallest useful diagnostic extract. Remove tokens, passwords, personal data, session material and remote pairing codes before sending logs.

## Privacy Shield Boundary

Privacy Shield protects text composed by Relay before provider delivery. Complete protection uses an isolated working directory; partial coverage keeps the provider inside the project and therefore cannot intercept autonomous file reads. Images are not anonymized. These boundaries are shown in the product and must not be represented as absolute protection.

## Supported Version

Security fixes currently target the latest released version only.

## Sensitive Files

Never commit `.env` files, diagnostic logs, remote sessions, pairing data, attachments, local vaults, provider credentials, generated worktrees or VSIX staging directories.
